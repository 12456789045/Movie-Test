# Movie Test

A React-based movie application that uses TMDB data to display popular films, movie details, and a watchlist.

## Features

- Browse popular movies and search results
- View movie details, trailers, and cast information
- Add movies to a watchlist
- Responsive UI with custom components and styling

## Project Structure

- `src/` - React application source code
- `public/` - Static web app assets
- `backend/` - Backend server files
- `src/components/` - Reusable UI components
- `src/pages/` - Application pages and route views
- `src/api/` - API calls and configuration

## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm start
   ```

3. Open the app in your browser at `http://localhost:3000`

## Notes

- Update TMDB API configuration in `src/api/apiConfig.js`
- Use the included `package.json` scripts for development and production builds
